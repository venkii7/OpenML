# Roadmap

## v1: Foundational Static Curriculum

- Next.js static export with TypeScript and Tailwind.
- Strict curriculum metadata for Levels 0 through 5.
- Lesson template and contribution checklist.
- First complete lessons for core ML: linear regression, logistic regression,
  gradient descent, evaluation metrics, bias-variance.
- Reusable interactive components for sliders, plots, residuals, and algorithm
  stepping.

## v2: Interactive Lab Layer

- Browser-based code cells for selected NumPy lessons.
- Code-to-visual sync for optimization, classification, attention, and RAG.
- Exercise system with hidden solutions and self-check prompts.
- Search, glossary, prerequisite graph, and progress stored locally.
- Community translation structure.

## v3: Professional Engineering Track

- End-to-end projects with datasets, model cards, deployment, monitoring, and
  incident writeups.
- Paper reading groups and annotated research notes.
- Maintainer dashboards for content health, stale references, and lesson gaps.
- Optional lightweight backend for accounts, saved progress, discussions, and
  cohort study groups.
